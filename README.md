<h1 align="center">Perpus Digital</h1>

<p align="center">
    E-Library dengan Laravel 11 dan bootstrap 5.
</p>

## Fitur
- User :
    - Dasbor katalog buku
    - Transaksi peminjaman buku
    - Cari & saring buku berdasarkan kategorinya
  
- Admins :
    - Analisis transaksi buku
    - Manajemen transaksi reservasi buku
    - Manajemen kategori
    - Manajemen buku

<br/>

## Prerequisite
* Laravel 11
* PHP 8.2+
* MySQL 8.3+
* AWS S3 Configuration

<br/>

## Cara Instalasi
1. Jalankan composer install untuk install dependencies
   
   ```$ composer install```
2. Import database sql
   
   ```import database yang bernama dbperpus.sql ```
   
3. Jalankan program webnya

   ketik perintah ```$ php artisan serve```


```NOTE:```
<br/>
Untuk merubah admin role database kriterianya:
<br/>
m: member atau user
